# Instructions

Follows the RV32I specification, as shown in image from: https://www.cs.sfu.ca/~ashriram/Courses/CS295/assets/notebooks/RISCV/RISCV_CARD.pdf

> [!Note]
> `j 0`/`jal zero` currently used to detect the end of the program.
> This is added in automatically after return from `main` when using the compile.sh script.
